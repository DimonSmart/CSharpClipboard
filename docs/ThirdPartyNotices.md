# Dependency inventory

CSharpClipboard uses Uno Platform 6.7.30 with Skia desktop rendering, .NET 10 and Microsoft.Data.Sqlite 10.0.13.

Third-party licensing and notices for Uno, SkiaSharp, HarfBuzz, SQLitePCLRaw, native SQLite and their transitive dependencies are provided by upstream package metadata. Release scripts copy relevant notices from the *resolved* NuGet package graph. Always audit the actual graph before distribution.

The app does not transmit clipboard content. Its only application HTTP request is a user-triggered GitHub stable-release check.
