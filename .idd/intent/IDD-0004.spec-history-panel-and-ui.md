# IDD-0004.spec-history-panel-and-ui

## Intent

Быстро находить и выбирать записи мышью и клавиатурой.

## Related Specifications

- IDD-0001
- IDD-0003
- IDD-0005
- IDD-0006
- IDD-0007

## Behavior

- ЛКМ tray/status icon или глобальная горячая клавиша открывает History. Повтор той же hotkey при открытой панели закрывает её без вставки.
- Открытие History **всегда перед активацией окна сохраняет paste target** (IDD-0005).
- При открытии поле поиска пусто, записи пересортированы. Если записи есть — выделена первая, фокус на списке; если записей нет — фокус на поиске.
- Стрелки вверх/вниз перемещают выделение. `Enter` выбирает Paste. `Cmd+Enter` на macOS / `Ctrl+Enter` на Windows — Copy Only. `Escape` закрывает. Команда Paste в контекстном меню и один клик по записи дают одинаковый результат.
- Pin/unpin — `Cmd+P` (macOS) / `Ctrl+P` (Windows); удалить — `Cmd+Backspace` / `Ctrl+Delete` (с учётом принятых платформенных conventions); полный preview — `Cmd+Y` / `Ctrl+Y`. Эти сочетания должны быть видны в подсказках соответствующей ОС, их конфликты проверяются. На Windows допустима явно задокументированная адаптация, не подмена скрытых сочетаний.
- Исключить двойную вставку от двойного клика, повторного Enter и одновременного pointer/key action.
- Заголовок окна History — `Clipboard History`; отдельная надпись с этим текстом внутри панели не отображается. Поиск и `Clear` расположены рядом; далее один список Pinned-first, строки с preview (wrap и схлопывание последовательных whitespace до пробела **только при отображении**), тонкая рамка с небольшим радиусом, hover-highlight и кнопка закрепления с иконкой булавки. Подсказка и доступное имя кнопки указывают действие `Pin` или `Unpin` в зависимости от состояния записи. Меню содержит Paste / Copy Only / Pin / Preview / Delete. В нижней части панели status выводится отдельно; status и keyboard hints имеют приглушённый серый текст, читаемый в обеих темах. Подсказки keyboard hints расположены слева в компактной строке, а справа у правого края содержимого панели находится кнопка с иконкой шестерёнки, доступным именем и подсказкой `Settings`.
- Источник и время копирования хранятся, но **не отображаются** в обычных строках списка.
- Пустой список — `Copy text to start your history`; отсутствие результатов — `No matches`.
- Полный контент открывается read-only, с возможностью выделения текста, без редактирования исходной истории; длинные значения не раздувают layout.
- Search filtering асинхронный/отменяемый: старый результат не имеет права заменить результат нового поискового запроса.
- Панель показывает снимок истории на момент открытия без фонового обновления; поиск работает по снимку. Явные команды изменения истории отражаются с сохранением порядка оставшихся строк (IDD-0003).
- Размер около **640×500 px** как ориентир референса; адаптируется под доступную область экрана и DPI/scale, центрируется на активном дисплее, не закрывает заголовок/system menu bar, поддерживает несколько мониторов.
- История ведёт себя как временная floating surface, умеющая получать keyboard focus; закрытие, Escape и click outside не производят Paste. Настройки и About — обычные окна. Не использовать `AlwaysOnTop` слепо, если это ломает desktop/Spaces/focus.
- Поддержка светлой/тёмной темы, высоких DPI, доступных названий полей для VoiceOver/Narrator, работа без мыши.
- Сохранить платформенную естественность: macOS — Cmd+..., macOS title bar и menu bar; Windows — Ctrl+..., tray и стандартные системные окна. Общее Uno UI не должно притворяться абсолютно одинаковым системным поведением.
- Уточнение к референсу: его Intent упоминает штатные close/minimize/full-screen controls; новый UI должен как минимум проверенно обеспечивать close/minimize, а на macOS fullscreen — при технической поддержке нативной панели. Если Uno floating window несовместима с native fullscreen, зафиксировать этот пункт как compatibility gap и вынести на решение, не выдавать неподдерживаемое за реализованное.


- Кнопка Clear рядом с поиском выполняет Clear Recent: удаляет незакреплённую историю, сохраняя pins.

## Product-Significant Architecture And Constraints

Поддерживаемые платформы и общие ограничения определяет IDD-0001. Наблюдаемые гарантии этого документа обязательны независимо от внутренней реализации.

## Non-goals

Нет редактора истории; неподтверждённый fullscreen не объявляется реализованным.

## Acceptance Criteria

- В заголовке окна History отображается `Clipboard History`; отдельной надписи `Clipboard History` внутри панели нет.
- Кнопка закрепления в каждой строке отображает иконку булавки; её доступное имя и подсказка указывают `Pin` или `Unpin` в зависимости от состояния записи.
- Кнопка с иконкой шестерёнки находится в строке keyboard hints, выровнена по правому краю содержимого панели и доступна как `Settings`.
- Status и keyboard hints приглушены серым, остающимся читаемым в светлой и тёмной темах; строка keyboard hints отделена от status небольшим вертикальным интервалом.
- Все команды доступны с клавиатуры и мышью, доступны для screen reader.
- History открывается на корректном мониторе и остаётся в видимой области после изменения DPI/подключения дисплея.
- Click вне панели, Escape, закрытие и повторный hotkey не вставляют текст.
- После pin/recopy порядок открытого списка не скачет; при повторном открытии пересортирован.
- Новые копирования не меняют открытый список и результаты поиска; при следующем открытии отображается актуальная история.

## Verification

Проверить заголовок окна History и отсутствие отдельной надписи `Clipboard History` внутри панели; иконку булавки на кнопке закрепления в строке и соответствующие состоянию доступное имя и подсказку `Pin`/`Unpin`; расположение кнопки с иконкой шестерёнки справа в строке keyboard hints, её доступное имя и подсказку `Settings`; компактный интервал строки keyboard hints от status и приглушённый читаемый цвет status и подсказок в светлой и тёмной темах; команды, focus, hover при прокрутке, отмену старого поиска, frozen ordering, DPI/displays, themes, VoiceOver/Narrator и закрытие без действия на обеих ОС.

Проверить снимок: открыть History, скопировать новый текст, убедиться, что список и поиск его не показывают; закрыть и открыть History и убедиться, что новая запись появилась. Проверить pin/unpin, Delete и Clear без добавления фоновых записей.
