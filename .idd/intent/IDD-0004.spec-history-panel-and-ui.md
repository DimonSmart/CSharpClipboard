# IDD-0004.spec-history-panel-and-ui

## Intent

Быстро находить и выбирать записи мышью и клавиатурой.

- IDD-0003

## Behavior

- ЛКМ tray/status icon или глобальная горячая клавиша открывает History. Повтор той же hotkey при открытой панели закрывает её без вставки.
- Открытие History **всегда перед активацией окна сохраняет paste target** (IDD-0005).
- При открытии поле поиска пусто, записи пересортированы. Если записи есть — выделена первая, фокус на списке; если записей нет — фокус на поиске.
- Стрелки вверх/вниз перемещают выделение. `Enter` выбирает Paste. `Cmd+Enter` на macOS / `Ctrl+Enter` на Windows — Copy Only. `Escape` закрывает. Команда Paste в контекстном меню и один клик по записи дают одинаковый результат.
- Pin/unpin — `Cmd+P` (macOS) / `Ctrl+P` (Windows); удалить — `Cmd+Backspace` / `Ctrl+Delete` (с учётом принятых платформенных conventions); полный preview — `Cmd+Y` / `Ctrl+Y`. Эти сочетания должны быть видны в подсказках соответствующей ОС, их конфликты проверяются. На Windows допустима явно задокументированная адаптация, не подмена скрытых сочетаний.
- Исключить двойную вставку от двойного клика, повторного Enter и одновременного pointer/key action.
- Панель: заголовок `Clipboard History`, поиск и `Clear` рядом, один список Pinned-first, строки с preview (wrap и схлопывание последовательных whitespace до пробела **только при отображении**), тонкая рамка с небольшим радиусом, hover-highlight и pin button, меню Paste / Copy Only / Pin / Preview / Delete; нижняя строка со status + keyboard hints и Settings.
- Источник и время копирования хранятся, но **не отображаются** в обычных строках списка.
- Пустой список — `Copy text to start your history`; отсутствие результатов — `No matches`.
- Полный контент открывается read-only, с возможностью выделения текста, без редактирования исходной истории; длинные значения не раздувают layout.
- Search filtering асинхронный/отменяемый: старый результат не имеет права заменить результат нового поискового запроса.
- При открытой панели до закрытия сохраняется порядок строк (IDD-0003).
- Размер около **640×500 px** как ориентир референса; адаптируется под доступную область экрана и DPI/scale, центрируется на активном дисплее, не закрывает заголовок/system menu bar, поддерживает несколько мониторов.
- История ведёт себя как временная floating surface, умеющая получать keyboard focus; закрытие, Escape и click outside не производят Paste. Настройки и About — обычные окна. Не использовать `AlwaysOnTop` слепо, если это ломает desktop/Spaces/focus.
- Поддержка светлой/тёмной темы, высоких DPI, доступных названий полей для VoiceOver/Narrator, работа без мыши.
- Сохранить платформенную естественность: macOS — Cmd+..., macOS title bar и menu bar; Windows — Ctrl+..., tray и стандартные системные окна. Общее Avalonia UI не должно притворяться абсолютно одинаковым системным поведением.
- Уточнение к референсу: его Intent упоминает штатные close/minimize/full-screen controls; новый UI должен как минимум проверенно обеспечивать close/minimize, а на macOS fullscreen — при технической поддержке нативной панели. Если Avalonia floating window несовместима с native fullscreen, зафиксировать этот пункт как compatibility gap и вынести на решение, не выдавать неподдерживаемое за реализованное.


- Кнопка Clear рядом с поиском выполняет Clear Recent: удаляет незакреплённую историю, сохраняя pins.

## Product-Significant Architecture And Constraints

Поддерживаемые платформы и общие ограничения определяет IDD-0001. Наблюдаемые гарантии этого документа обязательны независимо от внутренней реализации.

## Non-goals

Нет редактора истории; неподтверждённый fullscreen не объявляется реализованным.

## Acceptance Criteria

- Все команды доступны с клавиатуры и мышью, доступны для screen reader.
- History открывается на корректном мониторе и остаётся в видимой области после изменения DPI/подключения дисплея.
- Click вне панели, Escape, закрытие и повторный hotkey не вставляют текст.
- После pin/recopy порядок открытого списка не скачет; при повторном открытии пересортирован.

## Verification

Проверить команды, focus, hover при прокрутке, отмену старого поиска, frozen ordering, DPI/displays, themes, VoiceOver/Narrator и закрытие без действия на обеих ОС.
