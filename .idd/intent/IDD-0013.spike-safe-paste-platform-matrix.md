# IDD-0013.spike-safe-paste-platform-matrix

## Question

возможно ли в обеих ОС надёжно вставить выбранный текст в **то же** активное поле, откуда вызывали History, без accidental paste и недопустимых привилегий?

## Constraints

Контракты IDD-0001, IDD-0002, IDD-0004, IDD-0005, IDD-0009, IDD-0010 обязательны. Реальные macOS/Windows проверки не заменяются фейками; не логировать содержимое.

## Method

**Прототип:** hotkey → snapshot → простая панель выбора → copy → confirm original focus → paste shortcut OR Copy Only. Пока не требуется SQLite/полный UI.

**Проверить:** target focus changed, app switched, target exited, clipboard externally changed, protected field, terminal, browser form, VS Code, different keyboard layouts; macOS denied Accessibility/allowed, Windows elevated target/UIPI. Проверить не только факт отправки кнопок, но и реальную вставку harmless test text при нормальном исходном поле.

**Успех:** либо найден и доказан алгоритм guarded paste с положительными и отрицательными кейсами, либо задокументировано, в каких targets нужно гарантированно fallback, до внедрения всей UI-модели.

## Result

Вопрос открыт. Проверки нового приложения не выполнены. Evidence ClipboardMac не подтверждает CSharpClipboard.

## Recommendation

Проверить минимальный прототип до полноценного UI. Подтверждённое поведение перенести в спецификации, выбранные устойчивые решения — в ADR/Engineering; недоказанные возможности явно not verified.
