## Behavior

- Settings содержит **General** и только на macOS дополнительный раздел **Permissions**.
- General: **Launch at Login**, **Open History shortcut** с возможностью назначить или очистить сочетание, и малозаметная строка с путём к локальной истории.
- В Settings нет Retention, Exclusions, Pause/Resume, Data, Clear Recent, Clear All и длинных пояснений. История очищается кнопкой **Clear** в History или командой Clear Recent в меню значка приложения; pins сохраняются.
- **Permissions** на macOS: краткие статусы Clipboard и Accessibility, короткая подсказка про Always Allow/Accessibility и одна кнопка **Request permissions…**. Она запускает штатные запросы на оба разрешения и открывает системные настройки Clipboard; при возврате к окну статусы обновляются.
- Clipboard Always Allow требуется для фонового захвата; Accessibility требуется для guarded paste. Разрешения независимы; History и Copy Only работают без них.
- Prompt только вследствие действия пользователя. Не менять TCC напрямую, не отключать Gatekeeper/SIP, не запрашивать admin password.
- На Windows раздел Permissions не показывать: отдельное Clipboard-разрешение не требуется.
- На первом запуске открыть компактные Settings, не блокируя History.
- Launch at Login отображает фактическое состояние регистрации; информация об ожидающем одобрении macOS доступна в tooltip.
- Preferences сохраняются атомарно; устаревшие Retention/ExcludedApplications из предыдущих сохранений игнорируются.

## Product-Significant Architecture And Constraints

Поддерживаемые платформы и общие ограничения определяет IDD-0001. Нативные permission API принадлежат платформенному слою.

## Non-goals

Нет Data-раздела, настроек хранения, исключений и автоматического обхода системных разрешений.

## Acceptance Criteria

- General содержит только автозапуск, настройку хоткея и небольшую строку пути к истории.
- Windows: только General; macOS: General и Permissions с одной кнопкой запроса доступов.
- macOS Clipboard Default/Ask не трактуется как Always Allow; приложение может отсутствовать в системном списке до запроса.
- При deny и отсутствии Accessibility история и Copy Only доступны, повторных фоновых prompts нет.
- Существующие preferences читаются без потери Shortcut и Onboarded.

## Verification

Проверить UI на обеих ОС; clean macOS app bundle, deny/allow, Accessibility, возврат из System Settings; shortcut и startup в установленном приложении.
