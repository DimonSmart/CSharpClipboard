## Behavior

- Settings с разделами **General**, **Privacy**, **Data**.
- General: Hotkey, Launch at Login, Pause Capture, retention 50–2000 (начально 500).
- Privacy: текущий статус Clipboard Access (macOS), текущий статус Accessibility (macOS), кнопки `Request Clipboard Access Once`, `Open Clipboard Privacy Settings`, `Enable Accessibility for Automatic Paste…`, исключения по точным идентификаторам приложений; на Windows отобразить объяснение отличий вместо несуществующего Clipboard permission.
- Data: путь к локальной БД, ясная надпись, что история хранится нешифрованной на устройстве, Clear Recent, Clear All с confirmation.
- Первый запуск открывает Settings/короткое объяснение, но не блокирует History и Copy Only. Permission prompt только вследствие понятного пользовательского действия, кроме неизбежных системных prompts при реальном входе в защищённую операцию, который нельзя провоцировать фоновым polling.
- Status в меню и History содержит понятное описание: `Capture paused`, `Clipboard Access Required`, `Copy Only available`, `Automatic paste available` — в зависимости от фактических независимых состояний.
- Ошибки регистрируются без clipboard content. UI не предлагает пользователю отключать Gatekeeper/SIP/TCC или вручную сбрасывать TCC DB.
- macOS: `Clipboard Access Always Allow` — для автоматического захвата; `Accessibility` — для автоматической вставки; это разные разрешения. Возможны все комбинации: capture-only, paste-only/copy-only, full, neither.
- macOS Clipboard Privacy Settings: попытаться открыть соответствующую системную панель штатным URL/API, но предусмотреть fallback с точной текстовой инструкцией, если deeplink в данной версии ОС недоступен.
- macOS Accessibility: системное разрешение выдаёт пользователь; приложение не изменяет записи TCC и не запрашивает пароль администратора.
- Windows: автозапуск по пользовательскому согласию, состояние читать из реальной регистрации (например per-user Startup/task/registry — конкретный механизм выбрать и документировать), не запускать с elevated privileges.
- Exclusions: валидировать формат для каждой платформы, показывать пример, редактирование и сохранение; пользователь понимает ограничение best-effort attribution.
- Preference values сохраняются атомарно (без повреждения файла при аварии), обновления не стирают настройки; отдельная проверка совместимости версий.

## Product-Significant Architecture And Constraints

Поддерживаемые платформы и общие ограничения определяет IDD-0001. Наблюдаемые гарантии этого документа обязательны независимо от внутренней реализации.

## Non-goals

Нет изменения TCC DB, отключения защиты или запроса admin password.

## Acceptance Criteria

- macOS `.default` корректно объясняет, почему приложение пока не присутствует в System Settings clipboard list.
- При deny + отсутствии Accessibility история доступна, можно Copy Only, не возникает повторных системных запросов.
- Launch at Login показывает системное состояние, включая `requiresApproval`/pending, вместо ложного checked=On.
- Изменения настроек вступают в силу без рестарта там, где возможно.

## Verification

Проверить clean install из Finder, deny/runtime permission changes, независимость Clipboard/AX, Pause/Resume, atomic preferences, версии настроек и реальное состояние login после logout/login.
