# IDD-0006.spec-global-hotkeys

## Intent

Настраиваемая безопасная глобальная команда открытия History.

## Related Specifications

- IDD-0004
- IDD-0007

## Behavior

- Глобальную клавишу Open History пользователь выбирает в Settings; по умолчанию не назначена. Изменение применяется без перезапуска, сохраняется между запусками.
- UI показывает платформенное понятное обозначение модификаторов и клавиши, Recording control принимает новые комбинации без глобального keyboard hook.
- Нельзя регистрировать системные, небезопасные или обычные комбинации Paste; в частности учитывать зарезервированное Windows сочетание `Win+V` (системная clipboard history). При конфликте регистрации сохраняется старая работающая hotkey, выводится ошибка.
- Один callback не должен открывать и закрывать панель дважды; регистрация освобождается при Quit.
- macOS — `RegisterEventHotKey` (Carbon) или другой поддерживаемый API с документированным реальным поведением; Windows — `RegisterHotKey`/`WM_HOTKEY`. Глобальный Input Monitoring / low-level keyboard hook запрещён для MVP.

## Product-Significant Architecture And Constraints

Поддерживаемые платформы и общие ограничения определяет IDD-0001. Наблюдаемые гарантии этого документа обязательны независимо от внутренней реализации.

## Non-goals

Нет глобального keyboard hook и Input Monitoring.

## Acceptance Criteria

Смена и удаление hotkey без рестарта; явная ошибка занятой комбинации; Command/Control+V невозможно перехватить как Open History; регистрация после повторного запуска работает.

## Verification

Проверить смену, удаление, конфликт и повторную регистрацию hotkey; старая комбинация остаётся рабочей при отказе новой; Paste и системные сочетания не перехватываются.
