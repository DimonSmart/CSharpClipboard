# IDD-0008.spec-startup-and-distribution

## Intent

Устанавливаемое приложение, управляемый автозапуск и безопасная проверка релизов.

## Related Specifications

- IDD-0001
- IDD-0007
- IDD-0009
- IDD-0010

## Behavior

- macOS: дистрибутив — корректный `.app`, package ZIP/DMG; Windows: самостоятельный установочный/portable ZIP пакет с понятными командами запуска. Релизный пакет должен иметь проверяемый статус подписи.
- После установки приложение можно запускать **обычным способом через Finder/Explorer**, не требуя терминал, Swift/.NET SDK или ручной `dotnet run`.
- На macOS использовать `SMAppService.mainApp.register/unregister/status` или нативный эквивалент для Launch at Login; показывать approval state и направление в System Settings, если нужно. Не устанавливать скрытые LaunchAgents в обход пользователя.
- На Windows выбрать и документировать per-user автозапуск, корректно удалять при отключении/удалении приложения, не создавать scheduled task с повышенными правами.
- About показывает app version, проверяет stable GitHub Release (`DimonSmart/CSharpClipboard`), сообщает `current`, `newer`, `not available`, предоставляет ссылку на release.
- Формат релизных assets различается по ОС/архитектуре. Недопустимо скачать/установить macOS-артефакт на Windows или наоборот.
- **Обновление внутри приложения** допускается только после проверки доверия к пакету: неизменность скачанного artifact (например подписанный манифест/проверенный криптографический hash), корректная цифровая подпись производителя или иная проверяемая доверенная цепочка, bundle ID/архитектура/версия, безопасная staging + rollback/вывод ошибки. Проверка лишь `bundle id + version` недостаточна.
- Пока не настроена надёжная цепочка подписывания релизов, About может проверять/открывать Release Page, но **не** выполнять автоматическую замену исполняемого файла неподтверждённым архивом. Не выдавать ad-hoc signing за удостоверение издателя.
- Основная функциональность не требует check updates и не отправляет историю по сети.

## Product-Significant Architecture And Constraints

Поддерживаемые платформы и общие ограничения определяет IDD-0001. Наблюдаемые гарантии этого документа обязательны независимо от внутренней реализации.

## Non-goals

Нет установки неподтверждённых архивов; ad-hoc signing не удостоверяет издателя.

## Acceptance Criteria

- Обе платформы стартуют из установленного build без SDK.
- Новый stable release распознаётся, prerelease/draft игнорируется, офлайн/ошибки сети не ломают приложение.
- Update без доверенной подписи не устанавливается бесконтрольно; ошибок разрешений на запись достаточно для понятного fallback.

## Verification

Проверить установленные пакеты без SDK через Finder/Explorer, matching OS/arch, stable/prerelease/draft, offline/network errors, отказ недоверенному обновлению, регистрацию/отключение login.
