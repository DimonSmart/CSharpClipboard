# IDD-0005.spec-safe-paste

## Intent

Вставлять только в подтверждённое исходное поле; при недостоверности цели — Copy Only.

## Behavior

### Предусловия
- **В момент вызова открытия** (global hotkey/tray), **до** показа, активации и перевода фокуса на History, сделать snapshot прежнего target: приложение, процесс, окно, **конкретный focused element** или эквивалентный механизм проверки.
- Snapshot immutable на протяжении открытой панели. При выборе текста **не** искать заново произвольное «последнее активное окно» и не подменять исходную цель текущей.
- Защищённые поля паролей, неизвестный UI target, вышедший процесс, изменение окна/контрола/фокуса, смена приложения пользователем, запрещённая инъекция и недоверенный desktop означают **Copy Only**.

### Алгоритм
1. При OpenHistory — сохранить `неизменяемый снимок цели` и source fallback; если snapshot недоступен, UI работает, дальнейший Paste перейдёт в Copy Only.
2. При активации строки — атомарно принять единственное действие, сразу отклоняя конкурирующие повторные нажатия.
3. Скрыть панель. Записать выбранный **точный** текст в clipboard как plain text с маркировкой self-generated.
4. Запомнить ревизию буфера **после успешной записи**. Синхронизировать capture baseline так, чтобы не записать собственную копию и не потерять параллельное чужое копирование.
5. Для Copy Only — закончить без фокуса или синтетических клавиш; пользователь получает `Copied`.
6. Для Paste — восстановить **тот же** target (при необходимости активировать исходное окно, только если текущий foreground не стал сознательно другим приложением), проверить процесс/окно/контрол и секретность; проверить, что clipboard sequence ещё соответствует выбранному тексту.
7. **Непосредственно перед отправкой** единственного системного paste shortcut повторно перепроверить foreground, target и clipboard revision. При любой проблеме не отправлять shortcut.
8. Если допущено — отправить **одну пару** keydown/keyup обычной комбинации Paste (`Cmd+V`/`Ctrl+V`), не печатать символы по отдельности, не вызывать Execute/Run.
9. `shortcutSent` означает «события отправлены», **не** «текст гарантированно вставился». Нельзя показывать сообщение «successfully pasted», если target не подтвердил вставку.
10. При обычном Copy Only fallback (нет права, исходная цель потеряна) оставить выбранный текст в clipboard; показать `Copied. Press Cmd+V to paste` / `Copied. Press Ctrl+V to paste`.
11. **Особая гонка:** если после записи выбранного текста clipboard уже изменён другим процессом, не посылать Paste, не возвращать чужой clipboard к выбранному тексту и **не утверждать `Copied`**, поскольку выбранное уже не находится в буфере. Ввести отдельный исход `clipboardChanged` / `pasteCancelled` с понятным уведомлением (`Clipboard changed. Paste cancelled.`). Это намеренное исправление неточности референса, где такой случай мог выглядеть как `copiedOnly`.

### macOS особые условия
- Для чтения Accessibility элементов используется `AXUIElementCreateApplication`, `kAXFocusedUIElementAttribute`, `kAXFocusedWindowAttribute`, `AXUIElementCopyAttributeValue`; для первичного процесса `NSWorkspace.shared.frontmostApplication`.
- Разрешение **Accessibility** (`AXIsProcessTrusted`) проверяется отдельно от Clipboard Access; предлагается запрос через `AXIsProcessTrustedWithOptions(kAXTrustedCheckOptionPrompt)` только по явному действию. Без разрешения Paste всегда Copy Only.
- Secure controls (`kAXSecureTextFieldSubrole`) исключаются. Недоступность AX API в Chromium/Electron/terminal/remote-app => fallback, а не обход.
- Перед отправкой сверить исходные focused element/window, идентичность NSRunningApplication и frontmost app. Не активировать старое поле насильно, если пользователь сменил фокус/приложение.
- Отправка `CGEvent` с Command modifier через разрешённый механизм Event Posting. **Не** использовать глобальный event tap для перехвата клавиатуры/текста, не требовать Input Monitoring и Screen Recording для MVP.
- `Cmd+V` зависит от установленной клавиатурной раскладки. Перенести идею `определения клавиши Paste по раскладке` (TIS input source + `UCKeyTranslate`), протестировать US, Russian, Dvorak; не полагаться всегда на физический keyCode `V = 9`.
- Проверка AX доверия и правильного процесса особенно важна для `.app`, запускаемой из Finder (в отличие от `dotnet run` в терминале).

### Windows особые условия
- Snapshot: `GetForegroundWindow`, PID/TID (`GetWindowThreadProcessId`), `GetGUIThreadInfo` и, где необходимо, UI Automation element identity/RuntimeId. Часть controls не имеет отдельного HWND.
- Проверка после возврата target: PID/окно, фокус; если UIA не может надёжно подтвердить элемент, копировать без вставки. Не гарантировать точную идентичность одного HWND для Electron/Chromium/WinUI.
- Вставка через `SendInput` только в интерактивную desktop-сессию после проверки foreground. `SendInput` subject to UIPI; elevated target может быть недоступен не-elevated приложению. **Не** повышать privileges приложения и **не** обходить UIPI через бесконтрольное PostMessage.
- Ctrl+V с учётом реальной раскладки и состояния модификаторов, без удержания зависших виртуальных клавиш. На secure desktop, UAC prompt, password fields и RDP без надёжной идентичности — fallback.

## Product-Significant Architecture And Constraints

Поддерживаемые платформы и общие ограничения определяет IDD-0001. Наблюдаемые гарантии этого документа обязательны независимо от внутренней реализации.

## Non-goals

Нет посимвольной печати, автоматического Enter, обхода UIPI/TCC или слепой вставки.

## Acceptance Criteria

- При смене поля/окна/приложения между OpenHistory и Paste синтетических клавиш не отправляется.
- После появления чужой clipboard revision между выбором и попыткой вставки синтетических клавиш не отправляется, чужой clipboard не затирается повторной записью.
- За один пользовательский выбор допускается не более одного paste shortcut.
- Недоступная Accessibility macOS / UIPI Windows ведёт к Copy Only, без elevation и без аварии.
- Комбинация работает под минимум двумя раскладками на каждой ОС, в том числе одной альтернативной.
- Многострочный текст вставляется нормальным paste, без симуляции ввода символов и без автоматического нажатия Enter отдельно.

## Verification

Проверить clipboard/focus races и конкурирующие действия. Реальные цели: TextEdit/Notes, Safari, VS Code, Terminal; Notepad, browser form, VS Code, Windows Terminal. Проверить фактическую harmless вставку и отказы, права, раскладки; фиксировать только итог без текста.
