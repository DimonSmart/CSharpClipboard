# IDD-0001.spec-product-overview-and-lifecycle

## Intent

Быстрый доступ к локальной истории обычного текста Windows 11 x64 и macOS 26+ arm64.

## Behavior

- CSharpClipboard работает в пределах **интерактивной пользовательской сессии**, не устанавливает системную службу/демон с повышенными привилегиями.
- macOS: menu bar utility; значок в Dock по умолчанию отсутствует. Windows: значок в notification area (tray); главное окно при старте не открывается.
- ЛКМ по значку открывает History; ПКМ показывает контекстное меню. Если стандартная библиотека tray не обеспечивает такое разграничение на конкретной платформе, его реализует нативный адаптер, а не меняется требование.
- Контекстное меню: `Open History`, `Pause Capture` / `Resume Capture`, `Settings…`, `Clear Recent History`, `About`, `Quit`.
- При повторном запуске не создаётся второй монитор и второй инстанс для той же пользовательской сессии. Второй процесс сигнализирует уже работающему открыть History и завершается; если IPC невозможен, не допускается два одновременно пишущих экземпляра.
- Закрытие окна History/Settings не закрывает программу; команда Quit завершает мониторинг, освобождает горячую клавишу и нативные ресурсы.
- Начальный capture baseline устанавливается при запуске; уже существующее содержимое системного буфера **не** добавляется автоматически при запуске.
- Capture приостанавливается по команде. В режиме Pause не читаются данные clipboard и не выполняется запись в историю. При Resume устанавливается **новая** ревизия-отсчёт, пропущенное не импортируется.
- Запуск при входе в систему по умолчанию выключен, настройка отражает реальное состояние регистрации в ОС; включает только пользователь.
- Перезапуск/обновление сохраняет настройки, историю и pins.
- Приложение не требует сетевого соединения для основных функций.

- Безопасность важнее удобства: при недостоверной исходной цели только Copy Only. Приватность важнее полноты: подозрительное защищённое содержимое пропускается.
- Содержимое истории не передаётся в сеть, логи или аналитику. Сетевой запрос только для явно инициированной пользователем проверки обновления; автоматическая проверка требует отдельного изменения Intent.

## Product-Significant Architecture And Constraints

Поддерживаемые платформы и общие ограничения определяет IDD-0001. Наблюдаемые гарантии этого документа обязательны независимо от внутренней реализации.

## Non-goals

Первый релиз исключает изображения, файлы, самостоятельные RTF/HTML, OCR, AI, cloud sync, сторонние сервисы, редактор, коллекции/шаблоны, daemon, перехват всех клавиш, elevation, Linux, Windows 10, macOS до 26 и автоматическую миграцию ClipboardMac. macOS x86_64 и Windows arm64 не считаются поддержанными без проверки.

## Acceptance Criteria

- На каждой ОС запуск, повторный запуск, закрытие окон и Quit имеют ожидаемую семантику.
- Второй процесс не создаёт второе активное наблюдение clipboard и не приводит к повреждению БД.
- При запуске и Resume предшествующий clipboard item не импортируется.
- Pause полностью запрещает **чтение содержимого** буфера.
- Ошибка и отсутствие разрешения не закрывают приложение и не делают сохранённую историю недоступной.
