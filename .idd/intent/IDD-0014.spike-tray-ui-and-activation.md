# IDD-0014.spike-tray-ui-and-activation

## Question

обеспечивает ли Avalonia UI реальное left-click/open и right-click/menu в tray/status bar, корректный keyboard focus и безопасное macOS foreground snapshot **до** открытия панели, закрытие без action, DPI/multi-monitor?

## Constraints

Контракты IDD-0001, IDD-0002, IDD-0004, IDD-0005, IDD-0009, IDD-0010 обязательны. Реальные macOS/Windows проверки не заменяются фейками; не логировать содержимое.

## Method

**Решение:** при отсутствии точной parity использовать тонкий OS-specific tray adapter, сохраняя Avalonia для содержимого окна.

**Успех:** ручная демонстрация с двух платформ, no focus races.

## Result

Вопрос открыт. Проверки нового приложения не выполнены. Evidence ClipboardMac не подтверждает CSharpClipboard.

## Recommendation

Проверить минимальный прототип до полноценного UI. Подтверждённое поведение перенести в спецификации, выбранные устойчивые решения — в ADR/Engineering; недоказанные возможности явно not verified.
