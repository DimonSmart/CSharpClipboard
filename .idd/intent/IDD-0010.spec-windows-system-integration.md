# IDD-0010.spec-windows-system-integration

## Intent

## Behavior

- Windows 11 x64 (arm64 — желательно в будущем, отдельно проверить toolchain; не заявлять поддержку без тестирования). App запущен на обычном пользовательском уровне.
- Clipboard listener получает WM_CLIPBOARDUPDATE, отслеживает ревизию и обновляет history без перехвата клавиш.
- Для plain text преимущественно `CF_UNICODETEXT`; проверка форматов, нескольких представлений и нестандартных ownership; `OpenClipboard`/`CloseClipboard` всегда парные, handles и memory не текут.
- Registered clipboard markers и file-drop требуют реальной проверки Windows privacy; не сохранять clipboard data, явно исключённые из monitor processing.
- `RegisterHotKey`; single user instance, скрытое native window/message pump поддерживает message dispatch, даже когда все обычные окна закрыты.
- Tray icon, left/right click, menu, работа при scaling и нескольких мониторах.
- Paste snapshot по GetForegroundWindow/GetGUIThreadInfo + UIA, SendInput/контроль UIPI. Нет включения `uiAccess=true` или прав администратора по умолчанию.
- Windows-specific exclusions и private user profile directory/ACL.
- Уведомления об отказе из elevated app/UAC/secure desktop понятны; текст остаётся в буфере.

## Product-Significant Architecture And Constraints

Поддерживаемые платформы и общие ограничения определяет IDD-0001. Наблюдаемые гарантии этого документа обязательны независимо от внутренней реализации.

## Non-goals

Нет uiAccess=true или elevation по умолчанию; Windows arm64 не заявляется без проверки.

## Acceptance Criteria

- В нормальных приложениях copy/lookup/paste работает; в elevated window без доверенной возможности инъекции — Copy Only.
- Windows tray поддерживает двойной запуск без второго экземпляра; закрытие окна не завершает мониторинг.
- clipboard contention/необычные текстовые форматы не вызывают падение и не сохраняют мусор.

## Verification

На реальной Windows проверить listener/message dispatch без обычных окон, clipboard contention/formats, single instance, tray/scaling, UIA identity, UIPI/elevated/secure desktop и освобождение ресурсов.
