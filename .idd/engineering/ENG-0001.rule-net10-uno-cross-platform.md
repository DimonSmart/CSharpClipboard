# ENG-0001.rule-net10-uno-cross-platform

## Rule

.NET 10 и Uno Platform 6.7.30 с Skia Desktop для единого UI Windows/macOS. Native interop и tray/status item изолированы в платформенных адаптерах; Core/Services/Storage независимы от UI.

## Applicability

Always

## Applies when

Every implementation change

## Rationale

Фоновый clipboard manager работает без видимых пользовательских окон. Native event loops, Swift/AppKit main thread и Win32 notification-area item не должны зависеть от закрытия UI.

## Guidance

- Uno UI использует `net10.0-desktop`, Fluent, Windows Vulkan (явный `--software-rendering` для Software) и штатный macOS Skia renderer.
- `global.json` фиксирует Uno.Sdk, другие версии NuGet задаются централизованно.
- Core, Services, Storage и platform adapters остаются `net10.0` без Uno dependencies.
- Windows Shell_NotifyIcon adapter и macOS Swift NSStatusItem работают независимо от окон.
- Uno 6.7.30 `AppWindow.Hide` не реализует; используйте native hide с отдельным управлением native loop и Quit. Требуется интерактивная проверка каждой ОС.
- Windows 11 x64 и macOS 26+ arm64, Linux вне scope.
- Self-contained packaging, прежний bundle ID/signing identity.

## Verification

Build+test обеих ОС; отдельно настоящие интерактивные lifecycle, tray, paste, TCC, login и package smoke tests. Сборка сама по себе не является runtime evidence.
