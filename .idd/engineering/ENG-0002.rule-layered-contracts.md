# ENG-0002.rule-layered-contracts

## Rule

Сохранять направления зависимостей и платформенно-независимые контракты.

## Applicability

Always

## Applies when

Every implementation change

## Rationale

Явное ограничение исходного ТЗ сохраняет архитектурные границы, контролируемость реализации и проверяемость системной интеграции.

## Guidance

- `Core` не зависит от Uno, SQLite, AppKit, Win32 и native bridge.
- `Services` зависит только от Core contracts. `Storage` реализует HistoryRepository. Platform adapters реализуют OS ports. UI не обращается напрямую к Clipboard/AX/Win32/SQLite.
- Минимальные контракты: `IHistoryRepository`, `IClipboardPort`, `IPasteTargetPort` (с платформенно-типизированным snapshot), `IGlobalShortcutPort`, `IStartupRegistration`, `IPermissionStatusPort`, `ISettingsStore`, `IPlatformIdentity`, `IAppUpdater`.
- Разделить изменение clipboard и signal capture (`ClipboardSample`, `revision`, `text?`, `source?`, `protected`) и status `Allowed/RequiresAccess`.
- PasteService сериализует операции и принимает инжектируемые интерфейсы для deterministic tests. Не хранить нативные pointers/handles в сериализуемой модели.
- Сервисный слой не принимает решения по ОС по `OperatingSystem.Is...` в десятках мест; платформы выбираются только в DI composition root.
- ClipboardMac — behavioral reference, не зависимость/субмодуль; правило Swift/AppKit не переносится.
- Shortcut model хранит key и normalized modifiers; Carbon keyCode/Win32 VK и layout mapping принадлежат адаптерам.

## Verification

Проверить соответствие правилам этого документа обзором зависимостей/реализации и соответствующим automated или platform evidence. Реальные разрешения и поведение установленного пакета подтверждаются только на целевой ОС.
