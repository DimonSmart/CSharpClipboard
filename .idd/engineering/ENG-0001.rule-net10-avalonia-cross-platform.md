# ENG-0001.rule-net10-avalonia-cross-platform

## Rule

C# / .NET 10 и Avalonia; native API изолированы в платформенных адаптерах.

## Applicability

Always

## Applies when

Every implementation change

## Rationale

Явное ограничение исходного ТЗ сохраняет архитектурные границы, контролируемость реализации и проверяемость системной интеграции.

## Guidance

- C# и .NET 10 — общий runtime; UI — Avalonia UI. Версии NuGet зафиксированы централизованно, зависимости не должны случайно дрейфовать.
- Проект строится на Windows и macOS. Никакого WPF/WinForms в shared UI; Win32 interop только в Windows adapter, AppKit только в macOS adapter.
- Минимально поддерживаемые платформы: Windows 11 x64, macOS 26+ arm64; macOS x86_64 release target — при подтверждённой возможности сборки/проверке, а не автоматически считаться рабочим из-за успешного кросс-компилирования.
- Linux не входит в scope и не должен появиться фиктивной support badge.
- Предпочтение обычному self-contained publishing. NativeAOT — только отдельное оптимизационное решение после проверки Mac interop, UI, reflection и CI.

## Verification

Проверить соответствие правилам этого документа обзором зависимостей/реализации и соответствующим automated или platform evidence. Реальные разрешения и поведение установленного пакета подтверждаются только на целевой ОС.
