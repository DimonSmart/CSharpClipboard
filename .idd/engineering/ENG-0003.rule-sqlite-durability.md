# ENG-0003.rule-sqlite-durability

## Rule

Низкоуровневый SQLite driver, точные UTF-8 BLOB и атомарное версионированное хранилище.

## Applicability

Conditional

## Applies when

Изменение persisted history

## Rationale

Явное ограничение исходного ТЗ сохраняет архитектурные границы, контролируемость реализации и проверяемость системной интеграции.

## Guidance

- `Microsoft.Data.Sqlite` или эквивалентный низкоуровневый driver; ORM не нужен.
- Строгое содержимое UTF-8 как BLOB, SHA-256 candidate index + full-byte comparison, storage atomics и user_version migrations.
- SQLite connection serialized, `WAL`, `FULL` sync или отдельно подтверждённая политика, `secure_delete`, checked busy handling, checkpoint/VACUUM вне горячего capture path.
- Код миграций и DB errors покрыты тестами на обеих ОС. Platform storage path выбирается через native user application data API, не через текущую working directory.

## Verification

Проверить соответствие правилам этого документа обзором зависимостей/реализации и соответствующим automated или platform evidence. Реальные разрешения и поведение установленного пакета подтверждаются только на целевой ОС.
